## ✏️ How to Add Your Photos & Media

### Profile Photo
1. Save your photo as `assets/profile.jpg`
2. Refresh the browser — it loads automatically!

### Project Screenshots / Videos
1. Save your screenshot as `assets/project-ai-helper.jpg` (or `.png`)
2. Open `index.html` and find the project section comment:
   ```html
   <!-- Uncomment when you have the image:
   <img src="assets/project-ai-helper.jpg" ... />
   -->
   ```
3. Uncomment that `<img>` tag and comment out the placeholder `<div>`

### Certificate Images
1. Save scanned certificate as `assets/cert-mern.jpg`
2. In `index.html`, find the certificates section comment and follow similar steps.

## 📄 CV / Resume

Click **"View CV"** on the portfolio to open the CV page.
On the CV page, click **"Download / Print PDF"** to save as PDF using the browser's built-in print dialog.

> Tip: In the print dialog, choose **"Save as PDF"** as the destination and set margins to "None" for best results.
